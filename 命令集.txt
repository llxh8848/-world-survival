后续备份方法
每次改完代码，在项目目录运行：
git add -A
git commit -m "你的修改说明"
git push origin master

# 查看提交历史
git log --oneline

查看最近 5 次提交：

powershell
git log --oneline -5
查看最近 10 次：

powershell
git log --oneline -10
-数字 就是显示几条。--oneline 让每条提交只显示一行（编号 + 说明），简洁易读。


# 查看详细历史（包括改了什么）
git log -p

# 查看某次提交的详情
git show 94d3df7

# 查看所有分支
git branch -a

# 查看历史，找到 commit 编号
git log --oneline

# 临时回到某个版本看看（不影响当前）
git checkout 1bab809

# 看完后回到最新版本
git checkout master

# 彻底回退到某个版本（谨慎！会丢失之后的修改）
git reset --hard 1bab809
