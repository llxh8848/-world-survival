# 农业种植系统

## 概述
玩家可以种植作物，实现食物和材料的可持续生产，减少对野外采集的依赖。

## 种植方式
- 新工具：锄头（木锄/石锄/铁锄），用于翻地
- 右键草地用锄头翻地 → 变为农田
- 将种子扔到农田上 → 开始生长

## 种子来源
| 种子 | 获取方式 | 生长产物 | 生长时间 |
|------|---------|---------|---------|
| 苹果种子 | 吃苹果10%概率获得 | 苹果x3 | 5分钟 |
| 浆果种子 | 采集浆果20%概率获得 | 浆果x5 | 3分钟 |
| 柳条种子 | 砍树5%概率获得 | 柳条x3 | 4分钟 |
| 稀有木种子 | 砍稀有树10%概率获得 | 稀有木材x2 | 8分钟 |
| 仙人掌种子 | 采集仙人掌15%概率获得 | 仙人掌x3 | 6分钟 |

## 生长机制
- 农田需要靠近水源（5格内有水）→ 生长速度x2
- 篝火附近（5格内）→ 冬季也能种植
- 生长4个阶段：种子 → 幼苗 → 成长 → 成熟（成熟后右键采集）
- 骨粉（新掉落物，击杀骷髅类敌人获得）→ 加速1个阶段

## 新建筑：自动收割机
- 配方：铁锭x5 + 钻头x1 + 柳条x10
- 放在农田旁边，自动采集成熟作物并存储
- 类似自动挖矿器的存储界面

## 新建筑：温室
- 配方：木墙x8 + 玻璃（新材料）x4
- 3x3范围内作物不受季节影响，生长速度x1.5
- 需要建在农田上方

## 实现涉及的文件
- `data.js`：种子、锄头、骨粉、温室、自动收割机定义
- `world.js`：农田方块系统、作物生长逻辑、温室检测
- `player.js`：锄头翻地交互、种子种植交互
- `ui.js`：自动收割机存储UI
- `survival.js`：季节系统（可选）
- `index.html`：自动收割机UI HTML
