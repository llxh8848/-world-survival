# 元素系统扩展

## 概述
当前游戏已有 element_wood（元素木）、element_stone（元素石）、element_gold（元素金）三种元素材料，但元素金尚未有用途。本方案扩展元素系统的深度。

## 内容

### 1. 金锻造台
- 新建筑：金锻造台（用黄金 + 元素金 + 锻造台升级）
- 功能：用元素金将石质工具升级为"金质工具"
- 升级路线：石质工具 + 元素金 → 金质工具

### 金质工具列表
| 名称 | 属性 | 耐久 |
|------|------|------|
| 金剑 | 攻击+18 | 2000 |
| 金斧 | 砍伐力7, 攻击+10 | 2000 |
| 金镐 | 挖矿力7, 减少70 | 2000 |
| 金头盔 | 护甲4 | - |
| 金胸甲 | 护甲8 | - |
| 金护腿 | 护甲5 | - |
| 金靴 | 护甲3 | - |

### 2. 元素核心
- 配方：元素木 + 元素石 + 元素金 → 元素核心
- 用途：
  - 在黄金祭坛召唤"元素守护者"（比元素王更强的Boss）
  - 制作"元素套装"（全套装附带元素抗性）
  - 给锻造台充能，提升锻造成功率或附加属性

### 3. 元素附魔
- 在锻造台中放入元素核心 + 工具 → 附魔
- 附魔效果：
  - 火焰附魔（元素木）：攻击附带燃烧伤害
  - 坚固附魔（元素石）：工具耐久翻倍
  - 幸运附魔（元素金）：采集掉落翻倍

## 实现涉及的文件
- `data.js`：新增金质工具/装备定义、元素核心、附魔配方
- `ui.js`：金锻造台UI（复用锻造台3格布局）
- `world.js`：金锻造台3D模型、元素守护者Boss生成
- `enemies.js`：元素守护者Boss行为
- `player.js`：金锻造台交互
- `index.html`：金锻造台UI HTML
