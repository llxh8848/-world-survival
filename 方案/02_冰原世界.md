# 冰原世界（新维度）

## 概述
新增第三个维度——冰原世界，通过冰霜祭坛传送。永夜冰雪环境，有暴风雪debuff，需要篝火/火把才能生存。

## 传送方式
- 新建筑：冰霜祭坛（用冰晶 + 石墙 + 篝火 合成）
- 放入 3个冰晶 + 1个元素水（新材料）→ 传送至冰原世界

## 独特资源
| 资源 | 获取方式 | 用途 |
|------|---------|------|
| 冰晶 | 冰原挖矿 | 建造冰霜祭坛、冰质工具 |
| 冻木 | 砍冰原树木 | 冰质工具/装备 |
| 寒铁 | 冰原深层挖矿 | 高级冰质装备 |
| 元素水 | 冰原河流采集 | 传送材料、药水 |
| 雪球 | 冰原采集 | 投掷武器、合成材料 |

## 冰质工具
| 名称 | 属性 | 特殊效果 |
|------|------|---------|
| 冰剑 | 攻击+16 | 减速敌人30% |
| 冰斧 | 砍伐力6 | 砍树额外掉落雪球 |
| 冰镐 | 挖矿力6 | 挖矿速度+20% |
| 冰头盔 | 护甲3 | 免疫冰冻debuff |
| 冰胸甲 | 护甲6 | 免疫冰冻debuff |

## 环境机制
- **暴风雪debuff**：体温下降速度x3，需要篝火5格内或穿戴冰质装备免疫
- **黑暗惩罚**：冰原永夜，无火把时视野极短并持续掉血（1HP/5秒）
- **冰面打滑**：冰原地面行走速度降低，穿戴冰靴可正常行走

## 新Boss：冰霜巨人
- 3阶段Boss，固定不动但会召唤冰刺攻击
- 掉落：寒铁x10、冰晶x20、元素水x5、冰霜核心（用于制作终极冰装备）
- 需要在冰原世界用冰晶+寒铁+元素水召唤

## 实现涉及的文件
- `data.js`：冰原资源/工具/装备定义
- `world.js`：冰原世界生成（白色地形、冰树、冰矿）、冰霜祭坛模型、冰面物理
- `enemies.js`：冰霜巨人Boss、冰原怪物（冰虫、雪狼）
- `player.js`：冰霜祭坛交互
- `survival.js`：暴风雪体温机制
- `ui.js`：冰霜祭坛UI
- `index.html`：冰霜祭坛UI HTML
- `save.js`：冰原建筑存储
