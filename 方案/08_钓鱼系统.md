# 钓鱼系统

## 概述
新增钓鱼玩法，在河边用鱼竿钓鱼，获得食物、材料和稀有宝物。

## 钓鱼方式
1. 制作鱼竿：木棍x2 + 柳条x3 → 木鱼竿
2. 站在水边，手持鱼竿右键水面 → 抛竿
3. 等待鱼咬钩（浮漂抖动 + 提示音）
4. 再次右键 → 收竿，根据时机判断是否成功

## 鱼竿等级
| 鱼竿 | 配方 | 钓鱼速度 | 特殊 |
|------|------|---------|------|
| 木鱼竿 | 木棍x2 + 柳条x3 | 基础 | 无 |
| 石鱼竿 | 木鱼竿 + 元素石 | +20% | 可钓到稀有鱼 |
| 铁鱼竿 | 铁锭x2 + 柳条x5 | +40% | 可钓到宝箱 |
| 金鱼竿 | 铁鱼竿 + 元素金 | +60% | 必定双倍掉落 |

## 钓鱼产物
| 产物 | 概率 | 用途 |
|------|------|------|
| 普通鱼 | 50% | 食物（饥饿+20），可烤制（+35） |
| 大鱼 | 20% | 食物（饥饿+35），可烤制（+50） |
| 金鱼 | 10% | 稀有材料，可卖金币或合成 |
| 宝箱鱼 | 5% | 随机掉落（矿石/装备/元素材料） |
| 垃圾 | 10% | 树叶/骨头/腐肉（无用） |
| 神秘珍珠 | 3% | 终极饰品材料 |
| 藏宝图 | 2% | 使用后标记一个宝箱位置 |

## 钓鱼机制
- **夜间钓鱼**：稀有鱼概率x2
- **雨天钓鱼**：钓鱼速度+30%
- **雷暴钓鱼**：可钓到"雷电鳗"（特殊材料，用于雷电充能）
- **不同水域**：
  - 普通河流：普通鱼为主
  - 石头世界地下河：洞穴鱼、寒铁鱼
  - 金维度金河：金鱼概率x3
  - 冰原冰湖：冰鱼、元素水

## 烹饪扩展
| 菜品 | 配方 | 效果 |
|------|------|------|
| 烤鱼 | 鱼 + 篝火 | 饥饿+35 |
| 鱼汤 | 鱼 + 浆果 + 篝火 | 饥饿+40, 口渴+30 |
| 金鱼刺身 | 金鱼 + 海带 | 饥饿+50, 临时攻击+3（5分钟） |
| 雷电鳗料理 | 雷电鳗 + 苹果 | 饥饿+50, 临时速度+5（5分钟） |

## 新饰品：神秘珍珠
- 用3个神秘珍珠合成"珍珠项链"
- 装备后：钓鱼速度x2，水下呼吸（如果有水下机制）
- 配方：神秘珍珠x3 + 柳条x2 + 元素金x1

## 实现涉及的文件
- `data.js`：鱼竿、鱼类、烹饪、珍珠定义
- `player.js`：抛竿/收竿交互、钓鱼判定
- `world.js`：浮漂渲染、水域检测
- `ui.js`：钓鱼小游戏UI（时机判定条）
- `survival.js`：鱼类食物效果
- `index.html`：钓鱼UI HTML
