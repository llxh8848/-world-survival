# 成就/任务系统

## 概述
新增成就和每日任务系统，给玩家提供长期目标和即时奖励，增加游戏粘性。

## 成就系统

| 生存 | 存活1天、存活7天、存活30天 | 生存专家称号 |
| 社交 | 首次多人联机、与3人同时在线 | 友谊称号 |

### 成就UI
- 按 `Y` 键打开成就面板
- 显示所有成就：已解锁（金色）/ 未解锁（灰色 + 进度条）
- 解锁时屏幕弹出成就通知动画

## 每日任务系统

### 机制
- 每天刷新3个随机任务（游戏内每天，非现实时间）
- 任务难度随机，奖励与难度成正比
- 任务进度实时跟踪

### 任务示例
| 任务 | 条件 | 奖励 |
|------|------|------|
| 砍10棵树 | 砍伐10棵树 | 木材x10 |
| 挖20矿石 | 挖矿20块 | 石头x15 |
| 击杀5敌人 | 击杀5个敌人 | 熟肉x5 |
| 采集50浆果 | 采集50个浆果 | 苹果x3 |
| 锻造3次 | 锻造台锻造3次 | 元素石x2 |
| 充能2次 | 神秘盒充能2次 | 神木x1 |
| 建造5个建筑 | 建造5个建筑 | 木墙x20 |
| 不死存活1天 | 一天内不被击杀 | 金币x3 |

### 任务UI
- 主界面右侧显示当前3个任务及进度
- 完成时自动领取奖励 + 弹窗通知
- 按 `Y` 键在成就面板中切换查看成就/任务

## 称号系统
- 成就解锁的称号可以在聊天框前显示
- 例如：`[伐木大师] 玩家名: 大家好`
- 在设置中切换已解锁的称号

## 实现涉及的文件
- `data.js`：成就定义、任务定义、奖励映射
- `ui.js`：成就面板UI、任务追踪UI、通知动画
- `main.js`：成就/任务进度检查、每日刷新逻辑
- `player.js`：事件触发（砍树/挖矿/击杀时通知成就系统）
- `world.js`：建造事件通知
- `save.js`：成就/任务进度存储
- `index.html`：成就面板HTML
- `multiplayer.js`：称号显示在聊天中
