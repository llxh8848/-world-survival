# 地下洞穴系统

## 概述
在石头世界挖矿时有概率打开洞穴入口，洞穴内有稀有矿石、宝箱和专属怪物，需要火把照明。

## 洞穴入口
- 石头世界挖矿5%概率触发"地面塌陷"，打开洞穴入口
- 洞穴入口为3x3深坑，跳入后进入洞穴层
- 洞穴层独立于地表，有自己的区块生成

## 洞穴环境
- **完全黑暗**：无火把/光源时视野仅2格，持续掉血（1HP/10秒）
- **潮湿debuff**：体温下降速度x1.5
- **迷宫地形**：随机生成隧道、大厅、死胡同
- **矿物丰富**：铁矿、金矿、稀有石、寒铁（新）、钻石（新）

## 洞穴专属矿物
| 矿物 | 用途 |
|------|------|
| 寒铁 | 冰质工具/装备（与冰原世界共享） |
| 钻石 | 终极工具：钻石剑(攻击+25)、钻石镐(挖矿力8) |
| 红石 | 制作红石装置（自动门、感应器） |
| 化石 | 卖给NPC换金币 / 装饰品 |

## 洞穴怪物
| 怪物 | 行为 | 掉落 |
|------|------|------|
| 洞穴蜘蛛 | 快速移动，攀爬墙壁 | 蛛丝x2、毒液 |
| 蝙蝠群 | 群体攻击 | 皮革x1 |
| 骷髅 | 远程弓箭攻击 | 骨头x3、箭矢 |
| 洞穴巨人 | 高血量缓慢攻击 | 钻石x1、寒铁x3 |
| 史莱姆 | 分裂攻击 | 粘液球（合成材料） |

## 洞穴宝箱
- 随机出现在洞穴大厅中
- 需要用钥匙（骷髅掉落）打开
- 掉落：钻石、金矿、稀有装备、元素材料

## 返回方式
- 洞穴中有"爬梯"方块，右键使用返回地表
- 或死亡后自动返回地表（不掉落物品）

## 实现涉及的文件
- `data.js`：洞穴矿物/怪物/物品定义
- `world.js`：洞穴层区块生成、洞穴地形、矿物分布
- `enemies.js`：洞穴怪物AI
- `player.js`：洞穴入口交互、爬梯交互
- `survival.js`：黑暗掉血机制
- `save.js`：洞穴探索状态存储
